# Product: Haunted Feeds (RSS Resurrected)
Kiroween 2026, category **Resurrection**: bring RSS/Atom — a "dead" open technology — back to life with modern AI.
- Users follow sites (URL or OPML import); the app polls feeds and builds a **daily digest** with 2-sentence summaries.
- Must work with **zero API keys** (demo feeds + extractive summaries). LLM summaries are opt-in via `OPENAI_API_KEY`.
- Privacy-first: no accounts, no tracking, data stays in one JSON file.
- Tone: playful Halloween ("summon", "crypt", "graves") but readable; never sacrifice legibility for theme.
